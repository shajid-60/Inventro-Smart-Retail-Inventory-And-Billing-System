                        1. PROJECT OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

Project Name: Inventro
Description: A comprehensive Smart Retail Inventory and Billing System built with
             JavaFX that manages products, customers, billing, and revenue tracking.

Purpose:
    • Enable admins to manage inventory, track revenue, and view customer data
    • Allow customers to browse products, view ratings, and make purchases
    • Provide real-time stock management and revenue calculation
    • Implement a 15% markup pricing strategy for profit generation

Key Highlights:
    • Role-based authentication (Admin & Customer)
    • Real-time inventory tracking
    • Dynamic revenue calculation with 15% markup
    • Product rating system (1-5 stars)
    • JSON/PDF import functionality
    • Card-based product display with images
    • Responsive UI design with gradient backgrounds

6.1 RATING SYSTEM INTEGRATION
────────────────────────────────────────────────────────────────────────────────

A. Database Schema (DatabaseSetup.java)
──────────────────────────────────────────
Created a 'ratings' table with the following structure:

    CREATE TABLE IF NOT EXISTS ratings (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        productId INTEGER NOT NULL,
        userId INTEGER NOT NULL,
        rating INTEGER NOT NULL CHECK(rating >= 1 AND rating <= 5),
        comment TEXT,
        date TEXT NOT NULL,
        FOREIGN KEY(productId) REFERENCES products(id) ON DELETE CASCADE,
        FOREIGN KEY(userId) REFERENCES users(id) ON DELETE CASCADE,
        UNIQUE(productId, userId)
    );

Key Features:
    • Enforces rating range (1-5) using CHECK constraint
    • Prevents duplicate ratings with UNIQUE constraint
    • Cascading deletes when product/user is removed
    • Stores optional comments and timestamp

B. Data Access Layer (RatingDao.java)
──────────────────────────────────────────
Implemented methods:

    • insertRating(productId, userId, rating, comment, date)
        - Saves a new rating to database
        - Handles constraint violations

    • getAverageRating(productId)
        - Calculates average rating using SQL AVG()
        - Returns 0.0 if no ratings exist

    • getRatingCount(productId)
        - Counts total ratings for a product
        - Used for display purposes

C. Model Enhancement (Product.java)
──────────────────────────────────────────
Added rating fields:

    private double averageRating;
    private int ratingCount;

    // Getters and setters for rating fields

D. Product Data Access (ProductDao.java)
──────────────────────────────────────────
Enhanced findAll() method to include ratings:

    • Joins products table with ratings aggregation
    • Calculates average rating per product
    • Counts total ratings per product
    • Loads data asynchronously

E. UI Implementation
──────────────────────────────────────────
Customer Dashboard CardView:
    • Displays "⭐ [X.X] ([N] ratings)" format

    • Better visual hierarchy

Each product card is a VBox containing:

    VBox (Card Container)
    ├── Label (Product Name) - Bold, Large Font

    ├── Label (Stock) - Stock count
    ├── Label (Rating) - Stars + average
    └── Button (Add to Cart / Edit / Import Image)

Styling:
    • Background: rgba(17,34,51,0.85)
    • Border Radius: 16px
    • Padding: 16px
    • Drop Shadow: gaussian, rgba(0,0,0,0.75)
    • Hover Effect: Scale transform

C. Controller Implementation
──────────────────────────────────────────

ProductsController.java:
    @FXML private TilePane productCardContainer;

    private void loadProductsAsync() {
        executor.submit(() -> {
            List<Product> products = ProductDao.findAll();
            Platform.runLater(() -> {
                productCardContainer.getChildren().clear();
                for (Product p : products) {
                    productCardContainer.getChildren().add(
                        createProductCard(p)
                    );
                }
            });
        });
    }

    private VBox createProductCard(Product product) {
        VBox card = new VBox(8);
        card.setStyle("...");  // Gradient, shadows, etc.

        Label nameLabel = new Label(product.getName());
        Label categoryLabel = new Label(product.getCategory());
        Label priceLabel = new Label(
            String.format("$%.2f", product.getSoldPrice())
        );
        Label stockLabel = new Label(
            "Stock: " + product.getStock()
        );
        Label ratingLabel = new Label(
            product.getRatingCount() > 0
                ? String.format("⭐ %.1f (%d ratings)",
                    product.getAverageRating(),
                    product.getRatingCount())
                : "⭐ Not Rated Yet"
        );

        Button actionButton = new Button("...");

        card.getChildren().addAll(
            nameLabel, categoryLabel, priceLabel,
            stockLabel, ratingLabel, actionButton
        );

        return card;
    }

D. Responsive Design
──────────────────────────────────────────
    • TilePane automatically wraps cards based on width
    • prefColumns="3" suggests default 3-column grid
    • ScrollPane enables vertical scrolling
    • Cards resize proportionally
    • Minimum card width prevents text overflow

ProductsController.java:
    @FXML
    private void onImportImage() {
        Product selected = getSelectedProduct();
        if (selected == null) {
            showError("No Selection", "Select a product first");
            return;
        }

        FileChooser fileChooser = new FileChooser();
        fileChooser.setTitle("Select Product Image");
        fileChooser.getExtensionFilters().add(
            new FileChooser.ExtensionFilter(
                "Image Files",
                "*.png", "*.jpg", "*.jpeg"
            )
        );

        File file = fileChooser.showOpenDialog(stage);
        if (file != null) {
            String imagePath = file.getAbsolutePath();
            ProductDao.updateImagePath(selected.getId(), imagePath);
            selected.setImagePath(imagePath);
            refreshCards();
            showInfo("Success", "Image uploaded successfully");
        }
    }

9.2 ASYNCHRONOUS DATA LOADING
────────────────────────────────────────────────────────────────────────────────

Pattern Used:
    private void loadProductsAsync() {
        executor.submit(() -> {
            // Background thread: Database operations
            try {
                List<Product> products = ProductDao.findAll();

                // Switch to JavaFX Application Thread
                Platform.runLater(() -> {
                    // Update UI components
                    productCardContainer.getChildren().clear();
                    for (Product p : products) {
                        productCardContainer.getChildren().add(
                            createProductCard(p)
                        );
                    }
                });
            } catch (Exception e) {
                Platform.runLater(() ->
                    showError("Load Failed", "Could not load products")
                );
            }
        });
    }

Key Concepts:
    • executor.submit(() -> {...}): Submit task to background thread
    • Platform.runLater(() -> {...}): Update UI on JavaFX Application Thread
    • Thread Safety: Only JavaFX thread can modify UI components

9.3 DASHBOARD STATISTICS LOADING
────────────────────────────────────────────────────────────────────────────────
DashboardController.java:

    private void loadSummaryAsync() {
        executor.submit(() -> {
            try {
                List<Product> all = ProductDao.findAll();

                int total = all.size();
                int lowStock = (int) all.stream()
                    .filter(p -> p.getStock() > 0 && p.getStock() <= 5)
                    .count();
                int outOfStock = (int) all.stream()
                    .filter(p -> p.getStock() == 0)
                    .count();
                double stockValue = all.stream()
                    .mapToDouble(p -> p.getPrice() * p.getStock())
                    .sum();
                double revenue = OrderDao.getTotalRevenue();

                Platform.runLater(() -> {
                    totalProductsLabel.setText(String.valueOf(total));
                    lowStockLabel.setText(String.valueOf(lowStock));
                    outOfStockLabel.setText(String.valueOf(outOfStock));
                    stockValueLabel.setText(String.format("%.2f", stockValue));
                    revenueLabel.setText(String.format("%.2f", revenue));
                });
            } catch (Exception e) {
                e.printStackTrace();
            }
        });
    }

9.4 CHART RENDERING
────────────────────────────────────────────────────────────────────────────────
    private void loadChartAsync() {
        executor.submit(() -> {
            try {
                List<Product> all = ProductDao.findAll();

                List<Product> top10 = all.stream()
                    .sorted((a, b) -> Integer.compare(b.getStock(), a.getStock()))
                    .limit(10)
                    .toList();

                Platform.runLater(() -> {
                    XYChart.Series<String, Number> series = new XYChart.Series<>();
                    series.setName("Stock");

                    for (Product p : top10) {
                        series.getData().add(
                            new XYChart.Data<>(p.getName(), p.getStock())
                        );
                    }

                    stockChart.getData().clear();
                    stockChart.getData().add(series);
                });
            } catch (Exception e) {
                e.printStackTrace();
            }
        });
    }

10.1 ENCAPSULATION
────────────────────────────────────────────────────────────────────────────────
Example: Product.java

    public class Product {
        private Integer id;          // Private fields
        private String name;
        private double price;

    }
